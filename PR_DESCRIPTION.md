**Web**
- Journal photos (account only): one downscaled JPEG per entry, day-by-day history, a month calendar, optional self-reported sleep hours and a photo-and-sleep trend strip. Migrations `0002_journal_photos.sql` and `0003_sleep_and_suit.sql` must be applied to hosted D1.

- Suit check tab: manual Pass / Fail / Not checked inspection record with history and a Manual entry event on failure.

**iOS**
